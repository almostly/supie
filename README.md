# supie

Python edge functions and workflows for Supabase.

Write a plain Python handler, and supie builds it into an ordinary Supabase Edge Function that runs Python through Pyodide. Chain handlers into workflows with steps, run inline for real-time decisions or durably on pgflow.

supie is an independent almostly project, not an official Supabase product.

The [prototype](prototype/) shows the approach working on Supabase's Edge Runtime under the hosted limits.
